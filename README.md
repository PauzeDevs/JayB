# JayB Singh — Artist & Producer

A responsive, dark editorial-style portfolio concept for JayB Singh, built with plain HTML, CSS and JavaScript.

## Preview locally

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. GitHub Pages will provide the published URL once deployment completes.

A custom domain can be connected later from the same Pages settings. The domain must be owned and its DNS configured before it can be used.

## Before publishing as the official site

This is an initial visual concept. Replace or confirm the following with JayB or his team:
