# JayB Singh — Artist & Music Producer

A responsive artist portfolio concept for JayB Singh, built with plain HTML, CSS and JavaScript.

**Repository:** [https://github.com/PauzeDevs/JayB](https://github.com/PauzeDevs/JayB)

## Preview locally

No build tools or dependencies are required. Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. GitHub Pages will publish the site at the URL shown in the Pages settings.

A custom domain can be connected later from the same Pages settings after its DNS has been configured.

## Included

- Responsive editorial-style layout and mobile navigation
- Artist portrait sourced from JayB Singh's Apple Music artist image
- Selected releases and linked music credits
- Streaming links for Spotify, Apple Music, YouTube Music, YouTube, Amazon Music, Audiomack, JioSaavn, Deezer and Gaana
- Social profile links and PauzeX Developments credit

## Link accuracy

Direct Spotify, Apple Music and Audiomack artist pages are linked where identified. For platforms where a direct artist page could not be confidently verified, the button opens a platform search for JayB Singh rather than pretending an unverified URL is an official profile. The Instagram handle is linked as `@jaybsinghofficial`.

The portrait is loaded from the image CDN used by JayB Singh's Apple Music artist page. Before launch as an official artist website, confirm permission to use the portrait and have JayB or his team approve all copy, links and credits.
